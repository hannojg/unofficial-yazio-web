The page’s public configuration supplies Apple client com.yazio-website.siwa and callback https://www.yazio.com/app/login. AppleID.auth uses a popup. Its success event supplies an identity token, which the page submits as jwt with grant_type=sign_in_with_apple to /api/auth/token. The response contains access_token and refresh_token. The website uses client_id 7_9236kdzucvnd624cklgz787kcvhjfch6sbdejgmdv8387fj7v. The refresh request uses the same official endpoint. There is no need to use an embedded mobile client secret in this implementation.

The helper wraps fetch at document_start and copies successful /api/auth/token responses. It preserves YAZIO’s normal login. The service worker accepts the copy only from the YAZIO tab it opened for a user-started pairing and only for 10 minutes. The copy is forwarded to the originating desk content script. That script posts it same-origin to the private desk server, which checks the pairing cookie, validates the token against /v22/user, and encrypts the resulting session. The hosted app uses its platform identity boundary and binds the session cookie to that identity.

API base: https://yzapi.yazio.com/v22
GET /user — account display / search parameters / validate session
GET /user/widgets/daily-summary?date=YYYY-MM-DD — energy, macros, water, and goals
GET /user/consumed-items?date=YYYY-MM-DD — products, recipe_portions, simple_products
GET /products/search?query=...&sex=...&countries=...&locales=... — food search
GET /products/{uuid} — product nutrients and base unit
GET /recipes/{uuid} — recipe name
POST /user/consumed-items — products array with UUID, product_id, amount, daytime, full local date-time, nullable serving fields
DELETE /user/consumed-items — JSON object with bucket name mapping to a SINGLE entry UUID string
POST /user/water-intake — array with date and absolute water_intake in liters
POST https://www.yazio.com/api/auth/token — refresh grant for the website client

Live verification completed
- Official account page loads and offers Apple and Google sign-in.
- Anonymous /v22/user returns 401.
- Search with AT / male / en parameters returns 200.
- Product details for public cheese product 9dd1d51c-becf-11e6-9b02-e0071b8a8723 return 200.
- Nutrients are per ONE base unit: cheese energy is 3.86 kcal per gram, so 100 g is 386 kcal.
- Search requires countries and sex; omission returns field validation errors.
- Authentication, foreign-origin rejection, encrypted pairing cookies, wrong-nonce rejection, unpaired imports, and extension scoping pass automated local checks.
